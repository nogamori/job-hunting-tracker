Job Tracker

A free, browser-based job application tracker built with AI.

About

This tool was created using artificial intelligence by nogamori. It is open source, completely free to use, and runs entirely in your browser — no servers, no accounts, no subscriptions.

Features

  • ✓  Track companies and job applications in one place
  • ✓  Store CV files (PDF) alongside each application
  • ✓  Multi-entry notes with timestamps per application
  • ✓  Full change log for every application edit
  • ✓  Import applications via JSON (partial updates supported)
  • ✓  Filter and sort by tier, type, status, and more
  • ✓  Export and import all data as a single JSON file

How to use

  1. Download job_tracker.html and open it in your browser.
  2. Add companies you want to track using + Add company.
  3. When you apply to a role, click + next to the company to log the application.
  4. Update the application status as the process evolves.
  5. Use the Applications tab for a full view across all companies.
  6. Export your data regularly using the Export button.

Data & Privacy

All data is stored locally in your browser using IndexedDB — a built-in browser database. Nothing is sent to any server. Your data stays on your machine.

Important: data stored in IndexedDB is tied to the browser and device you are using. If you clear your browser data, use a different browser, or switch computers, your data will not be there. To avoid losing your data, export a JSON backup regularly using the Export button and keep it alongside the HTML file.

To restore data on a new device or browser: open the HTML file, click Import, and select your JSON backup.
