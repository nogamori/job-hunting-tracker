Features

  • ✓  Track companies, agencies and platforms in one place
  • ✓  Log job applications with status, CV file (PDF stored as base64) and notes
  • ✓  Multi-entry timestamped notes per application
  • ✓  Full change log for every application edit
  • ✓  Import applications via JSON (partial updates supported)
  • ✓  Bulk import companies via JSON
  • ✓  Filter and sort by tier, type, status, and more
  • ✓  Export and import all data as a single JSON backup file

How to use

  1. Download job_tracker.html and open it in your browser.
  2. Add companies using + Add company or import them in bulk via Import.
  3. When you apply to a role, click + next to the company to log the application.
  4. Update status and add notes as the process evolves.
  5. Use the Applications tab for a full view across all companies.
  6. Export your data regularly using the Export button — your data lives in the browser, not in the HTML file.

Data & Privacy

All data is stored locally in your browser using IndexedDB. Nothing is sent to any server. Your data stays on your machine.

Important: IndexedDB data is tied to your browser and device. Clearing browser data, switching browsers, or changing computers will erase it. Use the Export button regularly to keep a JSON backup alongside the HTML file. To restore, click Import and select your backup.

CV files are stored as base64-encoded strings inside the JSON backup. This means the backup file can become large if you attach many PDFs. If the file gets too large, consider removing old CV attachments from closed applications.

Import formats

Companies / Agencies / Platforms — via the Import button. Expects a JSON array. You can include applications inside each company using the apps field:

Field Required Description
nameYesCompany, agency, or platform name
tierNoPriority level. See valid values below
typeNoCompany, Agency, or Platform
urlYesMain website URL of the company (e.g. https://company.com). Used for the favicon icon and the clickable company name in the table
siteNoCareers page URL (e.g. https://company.com/careers)
linkedinNoLinkedIn Jobs page URL (e.g. https://linkedin.com/company/slug/jobs/)
notesNoFree text notes about the company
appsNoArray of applications (see application fields below)
 

[
  {
    "name": "Acme Corp",
    "tier": "1",
    "type": "Company",
    "url": "https://acmecorp.com",
    "site": "https://acmecorp.com/careers",
    "linkedin": "https://linkedin.com/company/acmecorp/jobs/",
    "notes": "Series B fintech, hiring commercial roles.",
    "apps": [
      {
        "role": "Account Executive",
        "url": "https://acmecorp.com/careers/ae",
        "date": "2026-09-01",
        "status": "applied",
        "notes": "Applied via company site."
      }
    ]
  }
]

Applications — via the Paste JSON tab inside the application modal. Open or create an application, switch to the Paste JSON tab, and paste. Only fields present in the JSON are updated; existing fields are preserved:

Field Required Description
roleNew onlyJob title / position name. Required only when creating a new application
urlNoDirect link to the job posting
dateNoDate applied, in YYYY-MM-DD format (e.g. 2026-09-01)
statusNoApplication status. See valid values below
notesNoText note to add. If ts is omitted, the current timestamp is used automatically
tsNoUnix timestamp in milliseconds for the note (e.g. 1756742400000). Defaults to import time if omitted
 

{
  "role": "SDR",
  "url": "https://acmecorp.com/careers/sdr",
  "date": "2026-09-01",
  "status": "applied",
  "notes": "Applied via company site. Recruiter: Jane Smith."
}
